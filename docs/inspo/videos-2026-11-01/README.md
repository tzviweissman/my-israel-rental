## Prompt template for one food shot (try it as a draft first)

```
[Shot, 3 s] Macro, 100 mm lens, camera locked with a very slow push in.
Subject: <their real item, exactly as in the start picture>, on <their real surface>.
Action (one only): <a hand / a spoon / gravity> <does one thing>; it lands at about 2 s and stays.
Material: thick, opaque, satin, slightly uneven, visible crumbs and pores; not glossy, not see-through.
Light: one large soft light from camera right; a narrow light behind and above that lights thin steam
wisps drifting left; the camera side darker; warm on the food, a little cooler behind, a few warm lamps far back.
Start picture: <A>. End picture: <B, the same item after>.
Do not: add or remove pieces, change the count or shape, float pieces into place, fade anything in,
add particles, glow, smoke, sparks or flash, make liquids clear or neon.
```
