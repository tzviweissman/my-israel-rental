## Orphaned capabilities

### New this round

1. **`POST /marketplace/courier/businesses/{business_id}/leave` has no frontend caller.**
   `backend/routes/marketplace/orders.py:1290-1291`. A courier who has accepted an
   invite from a business can be removed from the business's side
   (`DELETE /businesses/{id}/couriers/{key}`, wired in `OrdersTab.jsx:1244`), but has no
   way to remove themselves — `DeliveriesTab.jsx` has Accept/Decline for a pending
   invite but no "leave"/"stop working for this business" action once accepted. The
   endpoint exists and works; nothing calls it.
   **Fix:** add a "Leave" action per accepted-business card in `DeliveriesTab.jsx`. This
   is a small UI addition, not a design question — the backend side is done.

2. **`frontend/src/components/home/BlocksHero.jsx` (772 lines) is imported by nothing.**
   Superseded 11 Sep by `LoopHero.jsx`, which `HomePreview.jsx:38,179` now renders
   instead. Same pattern as the already-deleted `HeroSlideshow.jsx`.
   **Fix:** delete the file. Full sweep of all 196 `components/**/*.jsx` files found
   only this one orphan.

  messages): `Dashboard.js:404-410` alerts tab un-gated from `isRenter`;
  `GigDetail.jsx:44` `GIG_RETURN_PREFIXES` now includes `/businesses`;

  `allowed_payment_links`; the two other places that read payment links
  (`businesses.py:245` owner-scoped `_public()`, `businesses.py:799` public business
  page) were already correctly filtered or owner-only.
