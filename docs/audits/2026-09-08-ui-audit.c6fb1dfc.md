## Findings

**1. [Low] Dead imports in `backend/routes/misc.py`** — after the `/translate`
route was removed, `LlmChat`/`UserMessage` (from `utils.llm`) and
`ANTHROPIC_API_KEY` are imported but never used. No runtime effect, would be
flagged by a linter. *Fix:* delete the two unused imports.

**2. [Low] Orphaned Pydantic models** — `ContactRequest` (`backend/models.py:278`)
and `ServiceRequestOut`/`TranslationResponse` (`backend/models_response.py`) are
now unused after their only route was deleted. Not in this range's changed-file
set, so likely deferred on purpose. *Fix:* remove in a later cleanup pass.

**3. [Low] Stale hardcoded color reused in new buttons** —
`frontend/src/components/dashboard/MyGigsTab.jsx:502,539`,
`frontend/src/components/dashboard/CreateGig.jsx:517` (and the pre-existing
`MyJobsTab.jsx:114`) use `hover:bg-[#0F3A3A]`, a dark-teal hex from the
pre-"flow" palette that is not defined in `theme-flow.css` or
`design-tokens.css`. `SignupJoin.jsx:59` has a comment in the same diff noting
this exact color was replaced by `--ink` elsewhere, so the author was aware of
the change but didn't sweep these three buttons. Renders fine (raw hex, not a
CSS var, so nothing silently drops) — cosmetic drift only. *Fix:* swap to
`var(--brand-primary-deep)` or equivalent token.

**4. [Low] Physical (not logical) margins in the new thumbnail carousel** —
`frontend/src/components/ui/thumbnail-carousel.jsx:145-146` sets
`marginLeft`/`marginRight` via a Framer Motion animate variant. Both values are
always equal so it doesn't visibly break RTL today, but it's the one spot in an
otherwise RTL-careful pair of new components (`img-sphere.jsx`,
`thumbnail-carousel.jsx`) using physical properties. *Fix:* use
`marginInlineStart`/`marginInlineEnd` for consistency.

**5. [Low] Stale code comment** — `frontend/src/App.js:300` says the
`ServicesUpsellModal` component "still exists" (referring to
`/api/user/services-pitch/action`) — true of the endpoint, false of the
component, which this range deleted. No functional impact (nothing imports the
deleted component). *Fix:* update the comment to describe only the still-live
endpoint.

*Pre-existing, not introduced by this range (flagged in passing):*

## Verified clean

- **Gig pause/takedown authorization** (`backend/routes/marketplace/gigs.py`,
  `shared.py`): a provider cannot self-set `status=unpublished` (schema pattern
  rejects it, 422) and cannot hop `unpublished → paused → published` to undo an
  admin takedown (explicit 403 check) — two independent locks, both exercised by
  new tests (`test_a_provider_cannot_undo_a_takedown`,
  `test_someone_elses_listing_cannot_be_paused`).
- **Paused-listing reachability**: direct-link (`get_gig`) and booking
  (`book_gig`) paths now correctly 404/400 non-published gigs for non-owners;
  the public list endpoint was already filtering `status=published` before this
  change, so browsing was never exposed.
- **Price-filter fix** (`requests.py:552-585`): now genuinely converts currency
  (divides the ILS bound by the same 3.65 USD→ILS rate the frontend uses)
  before comparing, rather than just relabeling the field.
- **Dead-code removal**: all 5 deleted frontend components
  (`HeroSlideshow`, `PayPalCheckout`, `ServicesUpsellModal`, `PlanPicker`,
  `ServicesHeroTitle`) and the deleted `services_waitlist.py` backend route have
  zero remaining references anywhere in `frontend/src` or `backend` — only hits
  are in historical docs/PRD text. Backend router registration was cleanly
  removed alongside the file; startup will not crash on a missing import.
- **Bilingual completeness**: all 331 distinct `t()` keys used across the 18
  changed/new frontend files resolve in both `en.js` and `he.js`, including the
  dynamic `myJobs.status_${status}` key.
- **RTL**: no inline `fontFamily: 'Playfair Display'` in any changed file;
  `ImageGallery.jsx` uses logical `start-3`/`end-3` and swaps prev/next icons
  correctly for RTL.
- **Design tokens**: every `var(--brand-*)`/`--action`/`--ink`/`--font-head`
  reference added in this range resolves to a real definition.
