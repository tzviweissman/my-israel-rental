## New findings
1. [Low] Hebrew plural gap, businesses map. `services.mapCount` and `services.mapUnplaced` (added 20 Oct, 84aef6f) had `_one` and `_other` in `he.js` but not `_two`. Hebrew has a separate "two" form, so count 2 skipped both and fell to the English `defaultValue` (`ServicesMapView.jsx:213`, `Services.jsx:807`). Proof: i18next 26 with `lng: he`, keys `_one/_other` only: count 1 "one", count 2 "EN 2", count 3 "other 3"; after adding `_two`, count 2 returns the Hebrew text. Fixed below.
