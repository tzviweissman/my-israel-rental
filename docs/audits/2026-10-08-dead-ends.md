# Dead ends, 2026-10-08

Scheduled dead-ends audit following `.claude/skills/dead-ends/SKILL.md`. Static
analysis only: nothing was clicked (no MongoDB, no `node_modules` in this
environment). Forward pass done directly; backward and orphan passes by two
read-only sub-passes, whose key claims were spot-checked (marked CONFIRMED
below where I re-read the code myself).

Baseline: the 7 Oct fixes (`c279c33`, `9f66595`) hold. Of the 14 items carried
from 14 Sep, 5 are now fixed and 9 are still open (section "Orphaned").

## Broken: goes nowhere or errors

None found in navigation. Every static internal link target (479 string paths,
plus all `to=`/`navigate()`/`href=` templates) resolves against the 62 routes in
`App.js`. No empty handlers, no `href="#..."` anchors, every `target="_blank"`
carries `rel`. `/jobs?...` appears only in tests.

## Dead-end promises: destination lacks the affordance

1. **Guest booking status link is never delivered** (CONFIRMED, highest value).
   - Text: `bookingTrack.keep` "Keep this page: the business's reply appears here." (`BookingTrackPage.jsx` ~L108); `guestNote` "No account needed. You get a page that shows the reply." (`en.js` ~L4322).
   - Only delivery is a one-time `navigate(data.track_path)` (`GigDetail.jsx:239`). `book_gig` (`backend/routes/marketplace/gigs.py:1144-1250`) sends nothing to `contact_email`, and nothing is sent on accept/decline/expire. A guest who closes the tab, or who gave only an email, can never see the answer.
   - Fix: BUILD. Email `{FRONTEND_URL}/bookings/track/{token}` on create and on the provider's answer. Cheaper stopgap: change the copy to "Save this link".
2. **Jobs board: "Save this search" for an area saves a filter the board never applies** (CONFIRMED). `JobsBoard.jsx:50,85` reads `?area=` and saves it in the search; the fetch at `:105` sends only `category`, and there is no area control. Fix: send `area` in the query (the API accepts it, `jobs.py:356-362`) and add the control, or drop `area` from the save payload.
3. **Checklist and completeness panel disagree on "logo".** Checklist `biz.logo` "Add a photo or logo" ticks on `logo_url OR cover_url` (`onboarding.py` ~L162); `BusinessCompleteness` "Add a logo" counts `logo_url` only. A cover-only business is ticked in one and nagged in the other. Fix: change the promise, one shared rule.
4. **"Choose your categories" is a dead-end row.** `businesses.needCategory`, `action: null` in `BusinessCompleteness.jsx`; derived only from listings, no control. Fix: link it to the listings action, or relabel "Add a service to set a category".
5. **Feature-page CTAs land on the bare Overview.** `data/featureLibrary.js` lines 79, 116, 130, 144, 151: `cta: '/dashboard'` for "Get my link and code", "Connect my calendar", "Set this on my listing", "Look at my pricing", "See my numbers"; the controls live under `?tab=properties` / `?tab=my-businesses`. Lines 45, 93, 107 send non-providers to `?tab=my-businesses`, which shows the "no business" card (not blank). CTAs don't know the viewer's role. Fix: deep-link per role.
6. **"Saved" vs "Liked".** Toast `saved.done` says "find it under Saved in your dashboard"; the tab is labelled "Liked", title "Liked Properties", and shows "No saved properties yet" above saved services. Also `summary` loads once, so a non-renter's first save doesn't show the tab until reload. Fix: rename the tab "Saved", hide the empty state when items exist.
7. **Emails link to the Overview, not the control.** `utils/email.py:353-486` "View Booking" / "Open Dashboard" go to `/dashboard` (use `?tab=bookings`); `scripts/notify_missing_price.py:102` "Add a price" goes to `/dashboard` (use `?tab=properties`). Welcome email (`email.py:283`) offers "List your sublease in a few clicks" but the Subleases tab is renter-only; role-gate the line.
8. **"Repeat every week"** (`en.js:233`, "next week's copy appears on the board by itself") has no scheduler. `generate_standing_orders` (`orders.py:1809`) runs only on read. If nobody opens the Orders board or a customer view, nothing appears. Fix: add a daily loop or reword.
9. **Tour steps skipped silently**: `h.pricing` and `b.network` targets exist only on the first vacation property (`PropertyList.jsx:740,758`); a host without one loses the step with no notice. Low.
10. **Order emails use a relative link when env is unset**: `_frontend_url()` (`orders.py:1043`) and `payments.py:36` default to `""`; every other module defaults to `https://myisraelrental.com`. Low (fine when `FRONTEND_URL` is set on Railway).

- Admin request-reports UI, courier leave-business, check-in/out times, featured properties: fixed since 14 Sep.
- Checklist hrefs, `?edit=` emails, notification-settings links, review-request emails, "Feature this", email switches, 7 Oct fixes.
