## Improvement of the night
**Mechanism: the Fogg Behavior Model (ability: a behaviour fails when it costs more than the person will spend). Not previously proposed.**

**Surface:** the renter's contracts pane, `frontend/src/pages/Dashboard.js:433-443` (new `EmptyPane` with testid `contracts-not-lister`).

A renter arrives at `/dashboard?tab=contracts` from the "sign without printing" feature page wanting their contract. The pane explains where bookings are and offers a button, so they spend one more click and read a paragraph to reach a page the app already knows they need. Each added step lowers the share who arrive.

**Change:** for a non-lister on `tab=contracts`, call `navigate('/dashboard?tab=bookings', { replace: true })` in an effect instead of rendering the explainer. Keep `EmptyPane` as the fallback only if the bookings tab itself renders nothing for them.

**Expected if it works:** fewer sessions where a `tab=contracts` dashboard view by a non-lister is the last page view. Compare the existing page-view or view-tracking log for that tab before and after. If that log does not split by tab, say so rather than add tracking.
