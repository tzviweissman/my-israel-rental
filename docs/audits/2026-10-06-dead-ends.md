## Broken: goes nowhere or errors

1. **HIGH, "Verify Email" email button never verifies [confirmed by me].** `backend/routes/auth.py:83` builds `{origin}/verify-email?token=...`; `utils/email.py:294` renders it as "Verify Email". Route `/verify-email` (`App.js:415`) is `VerifyEmail.jsx`, which reads only `?status=` (default `invalid`, line 33) and never reads `token` or calls the API. The real verifier is `GET /api/auth/verify-email?token=` (`auth.py:405`), which then redirects to `/verify-email?status=...`. Result: every emailed link shows "Invalid link"; accounts stay unverified. Since `4486e3b` (16 Sep). **Fix (build):** point the email at the API route, or have `VerifyEmail.jsx` call the endpoint when `?token=` is present. Re-test signup > email > verify.
2. **HIGH, appointment bookings 400 [confirmed by me].** `routes/marketplace/gigs.py:1135` rejects appointment gigs without `time_slot` ("Please pick an available time slot"). `GigDetail.jsx` collects `appointmentDate`/`appointmentSlot` (296, 603), but `<BookingForm gig tier .../>` (1234) is not given them and POSTs only its own free-text `preferred_date` (217), never `time_slot`. WhatsApp bookings are unaffected. **Fix (build):** pass date and slot into `BookingForm` and send `preferred_date` + `time_slot`.
3. **MEDIUM, WhatsApp "Tap to read and reply" link is a 404.** `routes/chat.py:263` builds `chat?property_id=..&peer_id=..`; only `/chat/:propertyId` exists (`App.js:437`). **[confirmed by me]** Dormant unless Twilio is configured. **Fix:** `chat/{property_id}?with={sender_id}`.
4. **MEDIUM, blank dashboard panes.** `Dashboard.js:572` (`orders`) and `:587` (`job-requests`) render nothing unless `showGigTabs`; `bulk-manager` (`:516`) and `properties` (`:492`) need `isPropertyLister`. No `EmptyPane` fallback (unlike `my-businesses`/`contracts`). Reached from `data/featureLibrary.js:56` ("Try it", orders-and-delivery, public page), `:137` (many-at-once > bulk-manager), tour steps `b.orders`/`b.network`, and `?edit=`. A renter/owner without a business lands on a blank pane. **Fix (build):** add empty panes ("Add your business, free" > `/businesses/add`; "Add a property").
5. **LOW, sublease-signed notification** (`routes/subleases.py:415`, no `action_url`) routes via `Navigation.js:274` to `?tab=subleases`, which renders only for `isRenter` (`Dashboard.js:462`). Unverified whether a subleasor can be non-renter.
