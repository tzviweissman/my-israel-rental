# Dead ends - 2026-09-29

Scheduled dead-ends audit following `.claude/skills/dead-ends/SKILL.md`. Three parallel read-only passes (forward link resolution, backward promise-to-destination, orphaned capabilities) against `frontend/src/App.js`, `backend/routes/*` and the 123 commits since `2026-09-14-dead-ends.md`. **Static analysis only; nothing was clicked in a browser.** Nothing was fixed.

**Headline:** the 09-14 gaps are mostly closed (request-reports admin UI, courier leave, gig pause, item filters on the Requests board, Auth.js redirect). The new leak is on the **host / non-provider side**: three "Add your business" prompts send owners and renters to a blank tab, and two emails promise opt-out switches that do not exist.

## Broken: goes nowhere or errors

1. **`frontend/src/App.js:435`, `/chat/:propertyId`**: guard is `user ? <Chat/> : <Navigate to="/auth/login" />` with no return-to. Message emails link here (`backend/utils/email.py:514`, `:591`; `backend/routes/admin/chats_nudge.py:370`). The token is in sessionStorage, so an email opened in a new tab is always logged out: the user signs in and lands on `/dashboard`, and the conversation is lost. **Fix (build):** use `<ToAuth />` (App.js:74), which already preserves path and search.
2. **`frontend/src/App.js:437`, `/payment/success`**: same bare `Navigate`. PayPal returns here (`payments.py:170`, `marketplace/subscription.py:276`). An expired or fresh-context session sees login with `?flow=` / `?subscription_id=` dropped and the success handler never runs. **Fix:** `<ToAuth />`, or make the page work without a user and confirm server-side.
3. **`frontend/src/pages/CreateGig.jsx:603`**: `<PageMeta path="/services/create">`. No such route (real: `/services/create-gig`, `/businesses/add`). Canonical/OG URL of the "Add your business" page points at NotFound. SEO/link preview only. **Fix:** `/businesses/add`.
4. **`frontend/src/App.js:427`, `/admin`**: non-admin or not-yet-loaded session gets `<Navigate to="/" />` with no return-to. Typed-URL only, low. **Fix:** `ToAuth` when no user.
