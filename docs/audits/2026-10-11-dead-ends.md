## Broken: goes nowhere or errors

1. **Overview "Waiting on you" -> "Open"** (`OverviewTab.jsx:166`) goes to `job-requests` when no bookings wait. `Dashboard.js:607` renders that pane only when `showGigTabs`; a renter or property-only owner gets a blank pane and no sidebar highlight. **(confirmed)** Fix: route non-business users to `bookings`/`overview`, hide CTA when waiting is 0, or add an EmptyPane.
2. **Owner "contract signed" WhatsApp link** (`backend/routes/bookings/contract.py:243`) uses `dashboard?tab=bookings&booking_id=...`; Dashboard reads only `highlight`. Tab opens, booking not highlighted. **(confirmed)** Fix: use `highlight=`.

## Dead-end promises: destination lacks the affordance

1. **Emails say "Reply to this email"** (`backend/utils/email.py:405, 698, 964`; `routes/restaurants.py:548`). `send_email` sets no ReplyTo and From is no-reply@; no inbound handler found. **(ReplyTo absence confirmed; whether inbound mail is set up in Postmark is not verifiable here.)** Restaurant claim-approved email depends on this. Fix: set ReplyTo=CONTACT_EMAIL, or reword.
2. **Get-listed form**: "we will email you when you are listed" (`en.js:4928`, `GetListedForm.jsx:42`). `restaurants.py:416-445` `admin_decide` never sends email. Same for claim rejection (`en.js:4947`). Fix: send the emails or change copy.
3. **Business checklist "Add your service areas"** can never tick for a nationwide business: `onboarding.py:115-117, 174-178` ignores `serves_nationwide`, while `BusinessDetailsForm.jsx:326` offers it as the answer. **(confirmed)** Fix: project the field and use `areas or serves_nationwide`.
4. **Property checklist "availability"** (`onboarding.py:205, 234`) ticks on `available_from or ical_url`; the UI only writes `ical_urls` (plural), so a host who connects an iCal feed is never ticked. **(confirmed)** Fix: read `ical_urls`.
5. **Saved-search alerts** ("We'll email you when a new place matches", `en.js:2892, 2894, 3300, 3526`): `match_property_against_searches` runs only from `properties/crud.py` and `bookings/cancel.py`, not owner bulk upload (`routes/bulk_upload.py:406`) or admin import paths. Fix: call it after bulk insert (admin paths may be intentional).
6. **"The checkout cleaning reminder uses the check-out time"** (`en.js:1570`) with no pointer; the reminder exists only as a business-page automation. Fix: add the path or drop the sentence.
7. **Pricing tips toggle** (`en.js:1843`) promises a weekly note for any rental; the loop covers only vacation listings with Smart Pricing on. Fix: say so in the hint.
8. **Subscription**: a provider with an active PayPal subscription has no in-app way to cancel (`POST /marketplace/subscription/cancel` has no caller). Fix: build a cancel control (priority), or confirm no paid plans are live.
9. Minor: empty states with no CTA - `MyOrdersTab.jsx:86` ("Order from any store page"), `AppointmentsTab.jsx:304-307`. Property checklist items (photos, availability, share) land on the generic list rather than `?edit=<id>`.

## Wrong destination

## Orphaned capabilities

**Highest value**
- **Requests can't be edited.** `PATCH /marketplace/requests/{id}` / `RequestPatch` (`requests.py:222, 764`) has no caller; `MyRequestsTab` offers only found, renew, delete. A poster can't fix a typo, budget or WhatsApp number. **(confirmed no caller)** Build an EditRequestModal modelled on `EditJobModal`.
- **Published gigs can't change availability or contact**: `weekly_availability`, `slot_duration_minutes`, `enable_date_booking`, `booking_mode`, `whatsapp`, `contact_email`, `area`, `category`, `title_he`/`description_he` are create-only (`EditListingModal.jsx` header says deliberate). Fix: add availability/contact sections.
- **Owner can't pause a property.** `status: inactive` is admin-only (`admin/properties_bulk.py:683`); gigs have a Pause button.
- **Connection `relationship`** (`connections.py:43, 373`): `NetworkTab.jsx:151-154` renders a label nothing can set; `PATCH /connections/{id}` has no caller.
- **`WebsiteOrderIn.pay_by`** (`orders.py:1936`): `OrderPage.jsx` never sends it.
- **Brand film**: `POST/DELETE /marketplace/businesses/{id}/brand-film` have no caller; `BusinessPage.jsx:930` reads `biz.brand_film`.

**Lower**
- `RequestIn.furnished`, `amenities`, `subcategory` never sent by `PostRequest.jsx`.
- Manual sublease `amenities`, `property_type` never sent.
- `BusinessIn.categories`, `PropertyCreate.ical_url`, `PlanSelection`, `TranslationRequest`, `strict_only`, `default_role` unused.
- Enum values nothing writes: gig `draft`, property `archived`, restaurant `hidden` (no "Hold back" button), automation `land_in_status: ready`.
- Endpoints, no caller: `GET /marketplace/businesses/{id}/listings`, `GET /admin/marketplace/summary`, `GET /marketplace/subscription/plans`, `/subscription/select-plan|upgrade`, `GET /marketplace/business/{slug}/page-edits` (possibly redundant), admin-only with no UI: `auto-owner-nudge/status|run-now`, `/admin/email/diagnose`, `/admin/restaurants/pin-missing`, `businesses/{id}/page-v3` (ops/curl).
- Params no client sends: requests `category`/`rental_kind`; check-duplicate `area`/`title` (early return on short address); `/admin/gigs` `status`; jobs `subcategory`; subleases `area`.
- Legitimately external (keep): PayPal and tours webhooks, Google reviews callback, availability extend link, short-link follow, `/og/business`, tour poll cron, page-check endpoints, jobs `send-digest` manual trigger.

**Components imported by nothing:** none (script over 377 files). **Schedulers:** every loop defined in the backend is started in `server.py`.
