## Candidate rules for us
1. Before designing any section, pull at least 3 real references for that section type from Mobbin/Inspo and note what each leads with and why; adjacent categories count (a bakery hero can borrow from food delivery or editorial). (0:56-2:20, 2:30 SHOWN)
2. Use section-level search for a hero, social proof or CTA block, and keep the source link with each result. (5:00-5:10 SHOWN)
3. After a build, run a critique pass: give Claude the page screenshot and ask for a section-by-section critique with one reference per point and a ranked top five; then accept or reject each with a reason. (4:20-6:50 SHOWN)
4. Hero has one primary CTA, optionally one lighter secondary (for example "See menu"), not two identical buttons. (5:14-5:28 SHOWN/SAID)
5. Put truthful micro copy beside the CTA that lowers risk, using only facts the owner confirms: "Free quote", "No payment now", "Reply within 24 hours" if true. (5:46-5:57 SHOWN)
6. Add a short eyebrow label above the headline saying who and where it is for (for example "Home bakery, Modi'in"). (6:01-6:05 SHOWN)
7. Do not block value behind a form: show a taster of the service (menu, prices, work) before the enquiry form. (3:52-4:12 SAID; flow strips SHOWN)
8. Treat AI critique as input, not verdict. (6:26, 6:51 SAID)
