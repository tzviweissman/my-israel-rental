## EFFECTS (his list; trigger / build)
1. Scroll tracking: scroll progress 0..1 drives an animation (GSAP ScrollTrigger, Framer Motion useScroll). ALREADY-HAVE (scroll-scrubbed, pinned scenes).
2. Smooth scroll (Lenis / Locomotive) so scrubbed animation is not jerky from a mouse wheel. NEW as a named tool (our rules say "no taking the scroll"; Lenis is light inertia, not hijack). Suits scroll-film sites only; wrong for plain shop/booking pages.
3. Viewport detection: element enters view, animation plays (IntersectionObserver underneath). He says about half of all animations are this. ALREADY-HAVE (fail-safe .js-reveal).
4. Sticky position: plain CSS position:sticky for pinned scenes; no JS bugs. ALREADY-HAVE (sticky stage, rules ~526).
5. Easing sets the feel (slow, snappy, bouncy). ALREADY-HAVE (rule 17: never linear). Take: pick ONE easing per site as its personality.
6. Text splitting: paragraph into lines, words, letters (GSAP SplitText / SplitType), animate each part. NEW as a headline-reveal device. His warnings: hurts accessibility (keep aria-label on the whole text), breaks on resize (re-split). Suits bakery, salon, decorator hero headlines; wrong for long body text, and for Hebrew split by word only (letters join in RTL).
Bonus: map() (range remap, scroll 0..1 to scale), lerp (smooth cursor follower), shaders (artistic sites; skip for small businesses).
