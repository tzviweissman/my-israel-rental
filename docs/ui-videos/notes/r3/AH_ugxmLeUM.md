## For our pages

- Add a search field to any long choice list (products, packs, services) so people can find what they want without scrolling: white fill, no stroke, magnifier icon, grey placeholder such as "Search products".
- Always give a way out of an optional question: a small "Skip" pill (text plus thin right arrow) in the top corner.
- Add a filter icon button (sliders icon, same height as the search field, about 10px gap) beside the search field on a shop or listings page.
- Put a save/bookmark button at the top right of a product or booking detail, matching the "Back" pill on the left.
- Make the primary button one flat colour, no two-hue gradient; if a gradient is wanted, use only a lighter or darker shade of the same colour.
- Soften shadows: change the shadow colour to light grey (#D3D3D3), Y 3, blur 30, spread 0, 100%, rather than lowering opacity of black; or no shadow.
- Give stacked blocks more vertical space than feels needed (title, chips, description, list, action about 20px or more apart), especially on phones.
- Use a 3-column grid for tile pickers and a 2-column grid for product cards; let a scrolling chip row run off the edge on purpose.
- Build every card and chip with equal padding and gap so spacing repeats exactly.
- Give identical components identical shape: same height, radius, fill and placement for Back and Skip, and for every search field.
- Use one corner radius, 10px, on all small components (search fields, chips, Skip, Back, filter button, tags).
- Put a small icon on each product card (for example a flame beside calories) and replace the word "Save" with a bookmark icon in a small white 10px-radius chip.
- Use one icon set with one stroke weight (thin outline) across category chips and nav; choose icons from one library and download SVG.
- Label only lesser-known icons, with a dark tooltip bubble (small caps title over a one-line sentence); leave house, bookmark and user bare.
- Allow different icon styles only in separate zones (category chips, nav bar, small solid icons inside stat chips).
- Drop arrows that swipe already implies; let the last card or chip peek in at the edge to show there is more.
- Dim "See All" to mid-grey (about #777) and remove its arrow.
- Remove outlines on search fields, filter buttons and chips; use plain white tiles on the pale ground (dim the outline a lot instead if contrast is a worry).
- Show a selected tile with a 2px green border and a small green corner badge with a white tick.
- On tap, grey the main button (mid-grey, white label) and, if the wait is longer, show a small dark "Just a moment please" pill with a spinner just above it.
- Fill the bookmark solid on tap and show a small red dot on the Saved tab icon.
- Show a success note after an action (green check, short title, one line, "Done" button) rather than nothing.
- In charts, always give a vertical axis with 3 gridline values, keep one bar per label (7 days, 7 bars), use square-ish bar tops, and put the key figures with their change in small pills beside the headline number.
- Show the numbers a viewer needs (headline total, change pill, count) on a chart card even if it looks plainer.
- Sketch the flow on paper first and check for missing search, skip and filter controls.

## Not for us (dishonest or not applicable)

- Subscribe pill, "Consider Subscribing?" end card and the Figma file link: the presenter's own channel promo, not a page pattern.
- "Update installed!" confetti burst and the JUNIOR/SKILLED/WIZARD button sparkles and avatar cluster: decoration that adds noise (the video's own mistake 2), and the avatars would be invented faces.
- Red dot on the Saved tab is fine for a real new save only; never use red dots as fake notifications.
- Figma-specific steps (variables, styles, vertical trim, auto layout panel): design-tool actions; we do the equivalent with tokens and CSS.
- Dark task-list app, Flaticon/Phosphor/Feather sourcing: we already use lucide-react under the locked brand.
