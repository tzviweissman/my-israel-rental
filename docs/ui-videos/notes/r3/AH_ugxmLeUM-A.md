## Easy to miss

| Time | Detail |
|---|---|
| 3:16 | Every smaller component gets the same 10 px corner radius (search, chips, Skip, Back, filter, tags) |
| 1:38 | The shadow fix is a colour change (#D3D3D3, Y 3, Blur 30, Spread 0, 100 %), not just lower opacity |
| 5:14 | "See All" loses its arrow and is dimmed to grey, not left black |
| 5:24 | Strokes are removed from search bar, filter button and chips; tiles are plain white on the pale ground |
| 6:03 | Save gives two signals: filled icon on the card plus a red dot on the Save tab |
| 4:29 | Tooltips only on the two lesser-known icons (dice, chef hat); a dark-green bubble with a small caps label over a sentence |
| 4:37 | Different icon styles are fine if they live in separate zones (food, navbar, recipe) |
| 5:53 | Greyed-out button also gets a small "Just a moment please" loading pill with spinner |
| 2:34 | Text vertical trim set to "Cap height to baseline" so boxes hug the letters for exact spacing |
| 5:06 | Removing arrows works because the half-cut last item at the edge shows it scrolls |
