## Easy to miss

| Time | Before | After | Exact detail | Said |
|---|---|---|---|---|
| 1:44 | Default Figma shadow | Light-grey shadow with large blur | X 0, Y 3, Blur 30, Spread 0, #D3D3D3 at 100% (a light colour, not a low-opacity black) | Change the shadow colour to light grey and raise the blur instead of lowering opacity |
| 3:10 | Mixed radii | 10 px radius on all smaller components | Search fields, chips, Skip, Back, filter button, tag pills | Most designers miss this one |
| 2:34 | Text boxes with padding from line height | Vertical trim set to cap height to baseline | Figma Type panel Vertical trim toggle | Turn off vertical trim for pixel perfect control |
| 4:37 | One icon style app-wide | Different icon styles in separate zones | Food icons outline, navbar icons outline, recipe icons solid (flame, clock, star) | OK to mix, only if visually separate |
| 4:29 | Unlabelled tab icons | Tooltip only on the two unfamiliar icons (dice, chef hat) | "RANDOM TAB / Get a randomized recipe", "COOK TAB / Step-by-step cooking instructions" | Skip labels for house, bookmark, user |
| 5:12 | Black "See All ->" | Grey "See All" with no arrow | Colour dimmed to mid-grey | Dim down the colour of the button |
| 5:49 | Button looks idle while loading | Grey button + "Just a moment please" toast | Grey fill on press plus tiny spinner toast above | Grey out on click; add a loading wheel if long |
| 6:10 | Filled save icon only | Red dot on the Saved tab too | Red dot top-right of bookmark tab icon | Shows a new recipe was added to the save tab |
| 5:28 | Outlined chips and fields | Fill-only, stroke removed | White chips on grey-green ground | Rip strokes out; dim if contrast is a worry |
| 2:16 | Everything forced onto the grid | Small grid breaks left alone | Arrow button and chip row bleed past the last column | Leave it if it still feels balanced |
