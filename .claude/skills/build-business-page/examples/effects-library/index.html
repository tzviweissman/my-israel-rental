Effects library

Point at, tap and click each one. Switch the colours at the top to see it on a different business. Every option is built in plain code from a 21st.dev component or a real site found on Mobbin or Inspo, with nothing loaded from outside. This is a shelf of tested pieces: every build still searches fresh.
